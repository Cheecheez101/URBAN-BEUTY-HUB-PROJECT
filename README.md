\# Urban Beauty Hub Project



!\[Urban Beauty Hub Banner](screenshots/Homepage.png)



\*\*Urban Beauty Hub\*\* is a web application for a beauty salon in Nairobi, Kenya, showcasing their services, gallery, and booking system.



\## Features

\- Responsive homepage with service highlights

\- Services page with filterable categories and carousel images

\- Gallery of client transformations

\- Booking page with date/time selection

\- Modern UI with TailwindCSS and smooth animations



\## Tech Stack

\- Django (backend)

\- TailwindCSS (frontend)

\- Alpine.js for interactivity

\- MySQL/PostgreSQL (database)

\- SMTP email integration for booking confirmations
